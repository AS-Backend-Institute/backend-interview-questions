# Contributing

Thanks for helping make this the best free backend interview resource! 🙌

## How to add or improve a question

1. **Fork** this repository and create a new branch (`git checkout -b add-mongodb-questions`).
2. Add your question in the correct topic section of `README.md` using the existing format:

   ```html
   <details>
   <summary><b>N. Your question here?</b></summary>

   A clear, concise, correct answer (2–5 sentences). Add a short code block if it helps.
   </details>
   ```

3. Keep the numbering in order and update the counts in the **Contents** table if you add a new question.
4. Commit and open a **Pull Request** with a short description.

## Guidelines

- ✅ Answers must be **accurate** and **interview-ready** (short, not essays).
- ✅ Beginner-friendly language; add code only when it clarifies.
- ✅ A relevant "deep dive" link to a free tutorial is welcome (one per answer, no spam).
- ❌ No self-promotion, affiliate links, or low-quality/AI-dumped content.
- ❌ No duplicate questions — search first.
